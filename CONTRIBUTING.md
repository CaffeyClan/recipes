# Contributing to Our Family Meals

The recipes are intentionally stored in an easy-to-read format for current and future generations.

- To add a recipe, follow [`recipes/README.md`](recipes/README.md).
- To correct a recipe, open its file in the `recipes` folder and choose the pencil-shaped **Edit** button.
- Use the **Preview** tab before committing to check your formatting.
- Keep family tips and memories under **Family Notes**.

Only the files inside `recipes` need to be edited. The website code reads those files automatically.
